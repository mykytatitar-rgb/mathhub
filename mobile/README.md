# Android-збірка з рекламою і підпискою (Capacitor)

Це «нативна обгортка» навколо тих самих застосунків Anglo/Hola. Вона потрібна **тільки** тому, що реклама AdMob і оплата Google Play не працюють у чистому сайті — їм потрібен нативний код.

Код інтеграції вже написаний: `english/assets/js/native.js` і `spanish/assets/js/native.js`. Він сам вмикає рекламу й підписку, коли застосунок запущено в цій обгортці, і нічого не робить у звичайному браузері.

---

## ⚠️ Чесно про цей крок

| Що | Правда |
|---|---|
| Потрібен комп'ютер | так: Windows/Mac/Linux з **Node.js** і **Android Studio** (безкоштовні) |
| Можна зробити «в один клік» | ні — це реальна збірка Android-застосунку |
| Якщо немає досвіду / комп'ютера | або пройти кроки нижче повільно, або найняти Android-розробника на 1–2 години, або обрати простіший шлях: **підписка без AdMob через TWA** (див. `PWABUILDER_GUIDE.md`, Етап D, варіант 1) |

Метафора: сайт — готова квартира. Ця обгортка — «вбудувати сейф і касовий апарат» (реклама + оплата). Меблі не рухаємо — лише додаємо механіку.

## Кроки (одні й ті самі для anglo та hola)

Приклад для **anglo**; для Hola заміни `anglo` → `hola`.

```bash
# 0. Один раз: постав Node.js (nodejs.org) і Android Studio (developer.android.com/studio)

cd mobile/anglo

# 1. Встановити залежності (Capacitor + плагіни)
npm install

# 2. Скопіювати веб-застосунок усередину обгортки
npm run copyweb

# 3. Додати платформу Android (створить теку android/)
npm run add:android

# 4. Синхронізувати код і плагіни в Android-проєкт
npm run sync

# 5. Відкрити в Android Studio і зібрати
npm run open
```

У Android Studio: **Build → Generate Signed Bundle / APK → Android App Bundle**, створи ключ підпису (**збережи його!**) — отримаєш `.aab` для Google Play.

## Що вписати своїми даними (заміни заглушки)

| Файл | Що замінити |
|---|---|
| `english/assets/js/native.js` (і spanish) | `ADMOB_BANNER_ID` — блок «Banner» з AdMob; лишається тестовим, поки не готовий |
| `mobile/anglo/capacitor.config.json` (і hola) | `AdMob.applicationId` — App ID застосунку з AdMob (рядок `ca-app-pub-…~…`) |
| Google Play Console → Monetize → Subscriptions | створити підписку з ID `remove_ads` (саме такий ID очікує код) |

> Поки стоять тестові ID AdMob — реклама показується як «тестова». Це нормально: перед публікацією заміни на свої бойові, інакше Google може заблокувати акаунт за кліки по власній рекламі.

## Як це працює в коді (щоб ти розумів)

- `native.js` визначає, чи застосунок усередині обгортки (`Capacitor.isNativePlatform()`).
- На старті `app.js` викликає `Native.init(...)`: ініціалізує AdMob і Play Billing, питає магазин «чи куплена підписка», і вмикає/вимикає рекламу.
- Купівля на екрані «Без реклами» → `Native.buy()` → вікно оплати Google Play. Після успіху застосунок сам ховає банер (`isPremium()` стає `true`).
- «Відновити покупку» → `Native.restore()` (якщо перевстановив застосунок).

## Порядок усього запуску

```
1) Netlify: викласти english/ і spanish/ (LANG_APPS_GUIDE.md)
2) PWABuilder АБО Capacitor:
     • без реклами, тільки підписка → PWABuilder (простіше)
     • реклама AdMob + підписка   → Capacitor (ця тека)
3) Google Play Console: залити .aab, заповнити картку, підписку remove_ads
4) AdMob: створити блоки, вставити бойові ID
```
