# Google Play через PWABuilder — покроково

Ця інструкція перетворює вже викладений сайт (Anglo або Hola) на застосунок для Google Play. Роби спершу для одного, потім так само для другого.

> **Передумова:** сайт має жити онлайн за https (див. `LANG_APPS_GUIDE.md`, Частина 1). PWABuilder читає саме живу адресу, не файли з диска.

---

## Етап A. Зібрати пакет (без коду)

| # | Дія | Що побачиш / що ввести |
|---|---|---|
| 1 | Відкрий **pwabuilder.com** | поле для адреси |
| 2 | Встав адресу сайту (напр. `https://anglo-xxxx.netlify.app`) → **Start** | звіт: manifest, service worker, іконки — усе має бути ✅ (у нас так і є) |
| 3 | Натисни **Package for stores → Android** | відкриється вікно налаштувань |
| 4 | Заповни поля (таблиця нижче) → **Download** | завантажиться zip |
| 5 | Розпакуй zip | усередині: `app-release-signed.aab`, `assetlinks.json`, ключ підпису, інструкція |

### Поля у вікні Android

| Поле | Що ввести | Примітка |
|---|---|---|
| Package ID | `app.anglo.twa` (для Hola — `app.hola.twa`) | унікальний, латиницею, потім **не змінюється ніколи** |
| App name | `Anglo` / `Hola` | видима назва |
| Launcher name | те саме | під іконкою |
| Signing key | **Create new** | PWABuilder згенерує ключ — **збережи його й пароль!** Без нього не випустиш оновлення |
| Splash / theme | залиши з manifest | кольори підтягнуться самі |

---

## Етап B. Підтвердити домен (щоб не було адресного рядка)

Без цього застосунок відкриється, але зверху висітиме смужка браузера.

| # | Дія |
|---|---|
| 1 | У розпакованому zip відкрий `assetlinks.json` — там уже є твій `package_name` і SHA-256 відбиток. |
| 2 | Скопіюй його вміст у файл репозиторію `english/.well-known/assetlinks.json` (для Hola — `spanish/...`), замінивши шаблон. |
| 3 | `git push` → Netlify оновить сайт. Перевір, що відкривається `https://…/.well-known/assetlinks.json`. |

> ⚠️ Відбиток із PWABuilder — це відбиток **ключа завантаження**. Коли ввімкнеш «Play App Signing» у Console, Google дасть **ще один** відбиток — його теж додай у масив `sha256_cert_fingerprints` (їх може бути кілька).

---

## Етап C. Завантажити в Google Play

| # | Дія |
|---|---|
| 1 | play.google.com/console → **Create app** (мова інтерфейсу — українська, тип — App, безкоштовний). |
| 2 | **Production → Create release** → залий `app-release-signed.aab`. |
| 3 | Заповни картку: опис, значок **512×512** (`assets/icon-512.png`), 2–8 скріншотів телефона, банер. |
| 4 | Політика приватності (обов'язково, бо буде реклама) — потрібне посилання на сторінку. Можу згенерувати текст. |
| 5 | Анкети: контент-рейтинг, цільова аудиторія, безпека даних. |
| 6 | Надішли на перевірку. Перший розгляд — зазвичай кілька днів. |

## Етап D. Підписка (код уже написано ✅)

Підписка вже вбудована у застосунок (`assets/js/native.js`) через **Digital Goods API + Google Play Billing**. Вона працює прямо в TWA від PWABuilder — **без Android Studio, без коду з твого боку**. Тобі лишається одне: створити товар у Play Console.

### Що зробити руками (без коду)

| # | Дія | Деталі |
|---|---|---|
| 1 | Play Console → **Monetize → Subscriptions → Create subscription** | **Product ID** має бути точно `remove_ads` (саме цей рядок очікує код) |
| 2 | Додай базовий план і ціну (напр. ₴59/міс) | валюта підтягнеться в застосунок автоматично |
| 3 | Активуй підписку | після цього кнопка «Без реклами ⭐» у застосунку відкриє реальне вікно оплати Google Play |

### Як це поводиться

- **У застосунку з Play (TWA):** кнопка «Без реклами» → вікно оплати Google → після оплати HTML-банер зникає; є кнопка «Відновити покупку».
- **У браузері / на Netlify:** та сама кнопка працює як демо (вмикає локально) — бо оплата Google існує лише всередині Play-застосунку.
- Джерело правди — сам магазин: при кожному запуску застосунок питає Google, чи активна підписка.

### Про рекламу — чесно

| Тип реклами | Працює в TWA (цей шлях)? |
|---|---|
| **HTML-банер у застосунку** (елемент `#adslot`) | ✅ так — показується без підписки, зникає з нею. Сюди можна підключити веб-рекламну мережу, що дозволяє TWA |
| **Нативний AdMob** | ❌ ні — потребує нативної збірки (Capacitor). Це окремий, складніший шлях: `mobile/README.md` |

> Тобто freemium-механіка (реклама → підписка прибирає) готова й працює вже на цьому простому шляху. Нативний AdMob — це апгрейд «на потім», коли з'явиться доступ до комп'ютера чи розробника.

## Порядок дій (коротко)

```
Netlify (обидва сайти)  →  PWABuilder (.aab)  →  assetlinks у репо  →
→  Play Console: залив + картка + підписка remove_ads  →  готово
```
